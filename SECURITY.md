# Security policy

snowkit is a Go library for GTK4 and GNOME applications. It runs inside the
application that imports it, with that application's rights.

## Supported versions

Fixes go to the `main` branch and ship in the next `v0.x.y` tag. Only the
latest tag is supported; there are no backports to older tags.

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability
reporting: open <https://github.com/frostyard/snowkit/security> and choose
**Report a vulnerability**. Do not open a public issue for a vulnerability.

Include the affected tag or commit, the impact, and the steps to reproduce.
